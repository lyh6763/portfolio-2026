# Portfolio Submission Pitch

## 짧은 소개

정보 구조와 접근성을 기준으로 화면을 설계하고, 시맨틱 마크업과 반응형 UI로 구현하는 웹 퍼블리셔 이윤형입니다. 브랜드 리디자인 프로젝트를 통해 사용자 흐름을 정리하고, 모바일/데스크톱 환경에서 안정적으로 동작하는 퍼블리싱 결과물을 만들었습니다.

## 제출 메시지 예시

안녕하세요. 웹 퍼블리셔 직무에 지원하는 이윤형입니다.

포트폴리오에는 MARSHALL, DUOBACK, DUOBACK React 프로젝트를 중심으로 정보 구조 재설계, 시맨틱 마크업, 반응형 레이아웃, 접근성 QA 과정을 담았습니다. 단순히 화면을 구현하는 것보다 사용자가 어떤 순서로 정보를 이해하고 행동하는지를 먼저 정리한 뒤, HTML/CSS/JavaScript와 React로 구현했습니다.

아래 링크에서 작업물과 프로젝트별 구현 내용을 확인하실 수 있습니다.

- GitHub: https://github.com/lyh6763/portfolio-2026

## 프로젝트별 소개 문장

### MARSHALL

Marshall 브랜드의 스토리, 제품, 아티스트, 커뮤니티 콘텐츠가 한 페이지 안에서 자연스럽게 이어지도록 정보 흐름을 재구성한 원페이지 리디자인 프로젝트입니다. 모바일 메뉴, 푸터 아코디언, 스크롤 애니메이션의 접근성 상태와 반응형 레이아웃을 함께 점검하며 완성도를 높였습니다.

### DUOBACK

듀오백 브랜드의 제품 탐색과 구매 결정을 돕는 정보 순서를 중심으로 정적 쇼핑몰 UI를 재구성한 퍼블리싱 프로젝트입니다. 제품 가치 전달, 목록 탐색, 상세 정보 확인, 장바구니 흐름이 자연스럽게 이어지도록 페이지 구조와 카드 레이아웃을 정리했습니다.

### DUOBACK React

기존 DUOBACK 정적 리디자인을 React SPA로 확장한 프로젝트입니다. React Router 기반 라우팅, 상품 필터/검색, 제품 상세 선택, 장바구니 Context를 구현해 상태가 이어지는 쇼핑 경험을 컴포넌트 단위로 분리했습니다.

## 강조 포인트

- 사용자 여정 기반의 정보 구조 설계
- HTML5 시맨틱 마크업과 접근성 상태 관리
- 모바일/데스크톱 반응형 레이아웃 QA
- Vanilla JavaScript 인터랙션과 React SPA 구현 경험
- Git/GitHub Pages 기반 배포 및 최종 링크 검증

## 면접에서 짧게 말할 버전

제 포트폴리오는 브랜드 리디자인을 소재로 정보 구조, 시맨틱 마크업, 반응형 구현, 접근성 QA를 보여주는 데 초점을 맞췄습니다. MARSHALL은 원페이지 흐름과 접근성 개선, DUOBACK은 정적 쇼핑몰 퍼블리싱, DUOBACK React는 같은 브랜드 경험을 React SPA와 상태 관리 구조로 확장한 사례입니다.
